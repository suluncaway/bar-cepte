## ✨ Öne Çıkan Özellikler

- 📚 **600+ Kokteyl Veritabanı:** Popüler klasiklerden modern miksoloji reçetelerine geniş arşiv.
- 🧠 **Akıllı Bar Motoru:** Evindeki malzemeleri seç, anında yapabileceğin kokteylleri listele.
- 💡 **"Bunu Alırsan +X Tarif":** En az harcamayla en çok kokteyli açacak malzeme önerileri.
- 👑 **Bar Cepte Reserve:** Reklamsız deneyim, özel speakeasy seçkileri ve parti modu.
- 🍹 **Gelişmiş Filtreler:** Alkollü / alkolsüz, tat profilleri (tatlı, ekşi, sert, ferah).
- ⏱️ **Barmen Araçları:** Dahili çalkalama / karıştırma sayacı ve ekran açık tutma modu (Wake Lock).
- ❤️ **Kişisel Bar:** Favori kokteyller, fotoğraflı özel tarif ekleme ve eksik malzeme alışveriş listesi.
- 👥 **Parti & Porsiyon Modu:** 1x / 2x / 4x / 8x porsiyon çarpanı.
- 📱 **PWA & Çevrimdışı Çalışma:** Tarayıcıdan tek tıkla telefona uygulama gibi yükleme.
- ⚙️ **Cihazlar Arası Yedekleme:** Verilerini kodla anında başka bir telefona veya bilgisayara taşıma.

## 🧰 Teknoloji Yığını

- **Arayüz:** Vanilla JavaScript, Modern HTML5, Tailwind CSS
- **Veri & Önbellek:** TheCocktailDB açık veritabanı, yerel LocalStorage & Cache API
- **Web & PWA:** Service Worker (Offline-first mimari)
- **Masaüstü:** Electron + electron-builder
- **Mobil:** Android WebView Wrapper
